# ImageSitter 1.0.0

首个稳定版本，完成从窗口捕获、对象标记、样本校准到离线回归和脚本集成的完整工作流。

## 主要能力

- 客户区后台捕获、DPI/尺寸基准记录，以及固定、比例和锚点三种坐标策略。
- 多视觉状态、RGB/alpha 容差、排除点、最少命中数和邻域/缩放搜索。
- 正负样本校准、多样本智能选点、特征质量评分与低质量点清理。
- 多对象联合回放、连续录制、目录导入、并行执行、取消与 JSON/CSV/HTML 报告。
- 内嵌/外置样本、SHA-256 完整性检查、安全另存为、便携项目导出和残留清理。
- 自动恢复、撤销/重做、保存历史、对象模板、项目对比合并与 v1～v4 迁移。
- 独立 CLI，可用于项目校验、单帧匹配和 CI 回归。

## 验证

- 项目格式与坐标迁移测试 14 项通过。
- Rust GUI/领域测试 11 项、CLI 测试 1 项通过。
- TypeScript、生产前端构建、Rustfmt、严格 Clippy、NSIS 打包和 GUI 启动冒烟测试通过。

## 发布注意

- 安装程序尚未进行 Windows 代码签名，SmartScreen 可能显示未知发布者提示。
- 对外分发前需确认拥有随包提供 `winsitter.dll` 的授权。
- 自动更新需要发布方另行配置 HTTPS 更新端点和 Tauri 更新签名材料。
